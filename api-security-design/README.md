## 参照文献

- 『セキュアAPI 設計・構築・実装を貫く原則』第1〜12章、付録A。主要な参照元。第4〜5章はAPI脆弱性、第6章は設計、第7〜10章は認証・認可と基盤、第11〜12章は可観測性・テスト。
- 『セキュア・バイ・デザイン』。ドメインの概念、型、入力・不変条件と安全な設計の接続。
- 『APIデザイン・パターン』。リソース、標準メソッド、フィールドマスク、バッチ操作等のAPI契約設計。
- 『関数型ドメインモデリング』第5〜7章、第10章。型、不変条件、状態遷移、ワークフロー、エラー表現。
- 『つくりながら学ぶ！ドメイン駆動設計実践入門』第3章、第9〜15章等。境界づけられたコンテキスト、集約、トランザクション、アプリケーションサービス。
